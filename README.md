# AI in Orthopaedics & MSK 2026 — Hackathon

Team workspace for the **AI in Orthopaedics and MSK 2026** conference hackathon (5th Conference), organised by Clockwork Medical.

## Hackathon brief

> **"Formulate an AI based project to improve efficiency in your country's Healthcare system for MSK patients"**

## Key dates

| Milestone | Date |
|---|---|
| Hackathon registration closes | **1 August 2026** |
| All work submitted | **1 October 2026** |
| Best solutions announced | 15 November 2026 |
| Conference (Millennium Point, Birmingham) | 1–2 December 2026 |

## Submission requirements

- Python code in **Jupyter notebook** format
- Documentation describing the analysis, results, and **clinical implementation strategy**
- Team member list with contribution details
- Open-source data preferred
- Submit to: **samuel@clockwork-uk.com**
- All accepted hackathon presenters must register for the conference

## Repository structure

| Folder | Contents |
|---|---|
| [`medicine/`](medicine/) | Clinical background, MSK problem definition, clinical implementation strategy |
| [`technical/`](technical/) | Jupyter notebooks, code, data notes, model documentation |
| [`business/`](business/) | Efficiency/health-economics case, pitch material, presentation |
| [`group-member-contact/`](group-member-contact/) | Team member list, contact details, contribution log |
